# Knowledge Islands Website

The KI Website is the public publication for Knowledge Islands at [knowledgeislands.info](https://knowledgeislands.info). It turns selected philosophy, model, and practical tooling material into an accessible, independently deployable site.

## Place in the Knowledge Islands ecosystem

The website is not a canonical source of philosophy, engineering practice, agentic capabilities, executable tooling, or specifications. It vendors source-labelled material from [Arcadia Principal](https://github.com/knowledgeislands/ki-principal), which owns the Knowledge Islands philosophy, model and engineering discipline; the [KI Agentic Harness](https://github.com/knowledgeislands/ki-agentic-harness), which owns reusable agentic capabilities; [tools-ki](https://github.com/knowledgeislands/tools-ki), which owns the `ki` executable platform; and [KI Specifications](https://github.com/knowledgeislands/ki-specifications), which owns normative portable contracts.

That vendor model lets the website build and deploy autonomously while canonical ownership remains with each source repository. Arcadia's [ecosystem decision](https://github.com/knowledgeislands/ki-principal/blob/main/Admin/Governance/Decisions/GDR-KI-PRINCIPAL-006-knowledge-islands-ecosystem-fundamentals.md) defines the six authorities and publication flows, and the site provides stable public routes for [user installation](https://knowledgeislands.info/install/ki) and [repository bootstrap](https://knowledgeislands.info/harness/bootstrap).
